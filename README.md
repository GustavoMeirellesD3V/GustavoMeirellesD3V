## ` 01 ` Sobre

Estou aprendendo desenvolvimento web e prefiro aprender construindo coisa que vai pro ar
de verdade — não só exercício de curso.

Hoje meu foco é front-end: **HTML**, **CSS** e **JavaScript**, sem framework ainda.
A ideia é entender bem a base antes de subir de nível.

O projeto que mais me ensinou até agora é o **Carioca e Glow**, um sistema de agendamento
online para uma nail designer. Ele está em produção, com cliente real usando.

```text
stack atual      →  HTML · CSS · JavaScript
em produção      →  cariocaeglow.com.br
aprendendo agora →  JavaScript (a fundo)
```
